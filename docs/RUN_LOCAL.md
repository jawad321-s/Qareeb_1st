# تشغيل مشروع قريب على جهازك 🚀

دليل خطوة-بخطوة لتشغيل التطبيق (والأدمن) محلياً واختباره على هاتفك.

## المتطلبات (مرة واحدة)

| الأداة | من أين |
|---|---|
| **Node.js 22 LTS** (22.13 أو أحدث، مطلوب لـ Expo SDK 58) | https://nodejs.org (زر Download LTS) |
| **تطبيق Expo Go** على هاتفك | App Store (آيفون) أو Google Play (أندرويد) — ابحث "Expo Go" |
| الكمبيوتر والهاتف على **نفس شبكة الواي فاي** | — |

## 1) جلب الكود

```bash
git clone https://github.com/jawad321-s/Qareeb_1st.git
cd Qareeb_1st
git checkout claude/qareeb-home-services-oxn9td
```

## 2) تشغيل تطبيق الموبايل 📱

```bash
cd mobile
npm install        # أول مرة فقط (2-3 دقائق)
npx expo start
```

سيظهر **رمز QR** في الطرفية:

- **آيفون**: افتح الكاميرا العادية ← وجّهها على الـ QR ← اضغط الرابط ← يفتح في Expo Go
- **أندرويد**: افتح تطبيق Expo Go ← "Scan QR code" ← امسح الرمز

> 💡 إذا ما اشتغل الاتصال: اضغط `s` بالطرفية للتبديل إلى وضع Tunnel (أبطأ لكن يعمل على أي شبكة).

### تجربة سريعة بدون تسجيل
في أسفل شاشة الترحيب:
- **Demo: Customer** ← يدخلك تطبيق الزبون (أزرق)
- **Demo: Artisan** ← يدخلك تطبيق الحرفي (برتقالي)

### ملاحظات مهمة أثناء الاختبار
- **أول تشغيل بالعربي يُعيد تشغيل التطبيق تلقائياً مرة واحدة** (ثانية تقريباً) — هذا طبيعي: يضبط اتجاه RTL الأصلي ثم يثبت.
- **تبديل اللغة** (من الترحيب أو حسابي أو الإعدادات) يعيد تشغيل التطبيق — سلوك قياسي لقلب الاتجاه.
- صور البروفايلات والمعرض التجريبية تُحمّل من الإنترنت — تحتاج نت على الهاتف.
- بعد سحب تحديثات جديدة: هزّ الهاتف ← **Reload**، وإذا لزم امسح بيانات Expo Go.

### بديل سريع: المعاينة على المتصفح
```bash
npx expo start
# ثم اضغط حرف  w  بالطرفية — يفتح التطبيق في المتصفح
```

## 3) تشغيل لوحة الأدمن 🖥️ (طرفية ثانية)

```bash
cd Qareeb_1st/admin
npm install        # أول مرة فقط
npm run dev
```

افتح المتصفح على **http://localhost:3000**

- تسجيل الدخول على البيانات التجريبية: أي إيميل صحيح الصيغة + كلمة مرور 6 أحرف فأكثر
  (مثال: `admin@qareeb.app` / `123456`). على Firebase: حساب الأدمن بالإيميل (انظر FIREBASE_SETUP.md)
- زر `EN / ع` أعلى الصفحة لتبديل اللغة، وزر الخروج بالشريط العلوي

## 4) الربط الحي بين التطبيق والأدمن (اختياري)

افتراضياً كلاهما يعمل على بيانات تجريبية محلية بلا أي إعداد.
لتفعيل المزامنة الحية (Firestore) اتبع: [`docs/INTEGRATION.md`](./INTEGRATION.md)

## حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| QR لا يفتح / "timeout" | اضغط `s` بالطرفية لوضع Tunnel، أو تأكد من نفس الواي فاي |
| شاشة بيضاء بعد تحديث | هزّ الهاتف ← Reload، أو أعد `npx expo start -c` (مسح الكاش) |
| خطأ عند `npm install` | تأكد من Node 22.13 أو أحدث: `node -v`، ثم احذف `node_modules` وأعد التثبيت |
| الأدمن يفتح على صفحة الدخول دائماً | طبيعي — على البيانات التجريبية سجّل بأي إيميل صحيح وكلمة مرور (6 أحرف فأكثر)، وعلى Firebase بإيميل الأدمن. الجلسة تُحفظ بعدها |

## تشغيل على Firebase الحقيقي 🔥

الخطوات أعلاه تشغّل كل شيء على بيانات تجريبية. للتشغيل على Firebase (بيانات
مشتركة بين الجميع وتسجيل دخول حقيقي) اتبع
[FIREBASE_SETUP.md](FIREBASE_SETUP.md).
